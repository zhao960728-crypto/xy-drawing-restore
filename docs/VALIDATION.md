# 验证状态与适用范围

本功能是“AI 助手识图与编程工作流 + 本地提取、DXF 回读、参考尺寸检查和预览工具”，没有独立自动矢量化引擎。

2026-11-05 对公开前的 1.0.1 做过本地辅助脚本复查：24 项检查覆盖正确输入、inspect、preview、输入覆盖保护以及比例、漏页、未验证尺度、重复实体、来源变更、错误单位、嵌图等拒绝场景。公开版 1.0.2 的对应工具算法不变，仅添加许可/署名头和分发资料。

此前合成样本性能：i5-14400F、约 32 GB 内存、Windows Python 3.10；大部分项目测 3 次取中位数。5 页/帧提取约 0.50 秒、47 MiB；30 实体与 10 个参考尺寸检查约 0.67 秒、51 MiB；总览/分页/细节预览约 2.86 秒、300 MiB；10001 实体回读约 1.88 秒、87 MiB；10001 实体渲染约 9.58 秒、298 MiB（单次）。这些是公开前复查记录，非本次重新测得，也不含模型识图、编程、修图、审核或首次安装耗时。

已知效果边界：孔位移动 20 mm、改错文字，只要已检查的孔径和参考尺寸不变，自动尺寸检查仍可能通过，因此报告要求视觉复核。默认 0.05 mm 为核对容差，不能宣传为扫描还原精度。

尚无完整模型端到端还原准确率、真实复杂订单统计、Windows 原后台等价性或经平台安装后的实图验收证据。不把上传解析成功解释为市场审核通过、平台认证或制造验收。

公开仓库不收录原业务图纸、历史任务、原机器路径、性能原始工作目录或完整聊天记录。

## 公开版本复核与复现

1.0.2 发布前重新运行合成回归：5 页/帧原稿、30 个实体、10 个尺寸参考，prepare/check/inspect/preview 正常；14 类无效情况被拒绝，7 项输入覆盖保护检查通过。另通过技能元数据验证、Python 语法检查及 ZIP 内容/CRC 和敏感信息检查。这些仍是辅助脚本验证，不是完整 AI 还原效果验收。

开发验证可在独立环境安装 `requirements-dev.txt` 后运行：

```powershell

python tools/package_skill.py
```

回归仅生成合成 PDF、图片和 DXF，输出在被 Git 忽略的 `work/`；安装包输出在 `dist/`。测试依赖 reportlab 和 PyYAML 只用于开发验证，不随技能 ZIP 分发。
